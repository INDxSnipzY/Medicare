# MediCare 🏥

A modern healthcare platform designed to make medical information more accessible and help users discover nearby doctors.

## 🌟 Overview

MediCare is a healthcare web application focused on providing information about diseases, symptoms, medicines, prevention, and recovery. It also aims to help users find nearby doctors and access useful healthcare resources.

## ✨ Features

* 🩺 Medical information about diseases and symptoms
* 💊 Medicine-related information
* 🏥 Nearby doctor discovery
* 🛡️ Prevention and recovery guidance
* 💻 Modern, responsive user interface

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Library:** React
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Additional tools:** React Query, Axios, Framer Motion

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd medicare
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.
